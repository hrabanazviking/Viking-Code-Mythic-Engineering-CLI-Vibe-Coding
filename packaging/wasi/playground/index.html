Want to run the same WASI artifact locally with Wasmtime?

  • mythic-vibe.wasm (CPython compiled to WebAssembly, ~30-40 MB)
  • mythic-vibe.pyz (zipapp sidecar containing the CLI source, ~50-150 KB)

Then run locally:

wasmtime --dir=. mythic-vibe.wasm -- mythic-vibe.pyz doctor --json
